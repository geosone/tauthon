Limits before production use:

- Generic C embedding is not a Mystic A49 embedding test; that remains open.
- The full upstream test suite and complete Debian security-patch audit remain
  open. No security-maintenance guarantee is implied by this build.
- Legacy C extensions must be rebuilt and qualified, not copied as binaries.
- Removal leaves some interpreter-generated bytecode directories; a scoped
  bytecode-maintenance implementation remains open. User module directories
  must not be deleted indiscriminately.
- No Bookworm, ARM, Windows or future Debian release qualification yet.
- These are unsigned local Debian artifacts, not a configured APT repository.

No production BBS packages or data were changed by these tests.
